## Texture Editing Tips

For **Camellia Flowers**, edit to show:
- Pink/white camellia flowers (5-7 rounded petals)
- Yellow stamens in the center
- Remove red berries, replace with flowers
- Keep similar size and bush structure

For the **Camellia Flower item**, create:
- A single pink/white camellia bloom
- Similar style to vanilla Hytale plants
- Can reference real Camellia japonica flowers
- Keep the delicate, elegant appearance

## File Format

- All files are PNG format
- Maintain transparency where needed
- Keep similar resolution to source files
- Use Hytale's art style (slightly stylized, not ultra-realistic)
