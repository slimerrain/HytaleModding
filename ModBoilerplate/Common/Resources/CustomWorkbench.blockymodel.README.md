# Placeholder Model for Custom Workbench

This is a placeholder for the custom workbench 3D model.

## What You Need to Create

A **3D block model** (.blockymodel) showing your custom crafting table.

### Design Approach:
- Use Hytale's Block Editor or compatible 3D modeling tool
- Design a distinctive crafting station
- Consider functional elements (tools, materials, workspace)
- Make it recognizable and thematically appropriate

### Model Requirements:
- **Format**: .blockymodel (Hytale's proprietary format)
- **Dimensions**: Typically 16x16x16 units (1 block), but can be 16x14x16 for workbenches
- **File Name**: CustomWorkbench.blockymodel
- **Path**: `Common/Resources/CustomWorkbench.blockymodel`

### Example Designs:
1. **Basic Workbench**: Wooden table with tools scattered on surface
2. **Forge**: Stone base with anvil and hammer
3. **Loom**: Vertical frame with fabric stretched between posts
4. **Alchemical Table**: Lab equipment, bottles, burners

### How to Create:
1. Open Hytale Block Editor (in-game or standalone tool)
2. Design your crafting table model
3. Add functional details (tools, materials, decorations)
4. Export as .blockymodel
5. Save to this folder with correct name
6. Delete this placeholder file
