   - Template for item definitions
   - Change the filename and edit the contents

   - Translation file

4. **Common/Icons/ItemsGenerated/** (Add to this)

   - Filenames must match item IDs

## 💬 Quick FAQs

**Q: Do I need to create all the folders?**
A: No! They're all already created.

**Q: Can I delete empty folders?**
A: Yes, delete what you don't use. Keep `Server/Item/Items/` and `Server/Languages/en-US/`.

**Q: What if I'm making blocks instead of items?**
A: Same structure! Just use Template_Block as the parent.

**Q: Can I use multiple languages?**
A: Yes! Copy Server/Languages/en-US/ to fr-FR/, de-DE/, etc.

**Q: How big can my mod be?**
A: As big as you want! This scales from 1 item to 1000+ items.

**Q: What if I get stuck?**
A: Check INDEX.md for Q&A, or search the README for your issue.
